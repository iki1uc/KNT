# ((KNT)) · iki1uc

KNT ist das zweite Modul der neuen drei‑Zonen‑Struktur:

1. **WAS** — Ausgangspunkt / Vorzone  
2. **KNT** — Möglichkeit / könnte  
3. **WEN** — Trigger / wenn

KNT bildet die 120°‑Achse im iki1uc‑System und steht für alle
„könnte“-Zustände, also die Möglichkeitsebene zwischen Ausgangspunkt
und Trigger.

## Achsen (360°)
- **WAS (60°)** — Vorzone / Ausgangspunkt  
- **KNT (120°)** — Möglichkeit / könnte  
- **WEN (180°)** — Trigger / Aktivierung  
- **W0HRE (240°)** — Realität / Bindung  
- **EVO µ EVO (300°)** — Skalierung  
- **ROOT (360°)** — Vollkreis / Erfüllung

## Funktion
KNT ist die Zone, in der ein Zustand möglich wird, aber noch nicht
ausgelöst ist. Es ist die Brücke zwischen WAS und WEN.

## respo-Layer
OK · NOK · FLOW · BREAK · ECHO · VOID · ROOT

KNT wird im respo-Layer als Möglichkeitssignal genutzt, bevor WEN
aktiv wird.

## DA(xx)MIT-Bindung
KNT koppelt an DA(xx)MIT über die 120°‑Achse:

- DA(SOLL)MIT → KNT soll aktiv werden  
- DA(IST)MIT → KNT ist aktiv  
- DA(score.soll)MIT → KNT erzeugt Score-Fusion  
- DA(advanced.soll)MIT → KNT skaliert EVO µ EVO
